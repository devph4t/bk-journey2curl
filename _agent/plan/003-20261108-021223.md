# Plan 003: M2 – runbook and report (HTML, JSON, Markdown)

Created: 2026-11-08 02:12:23 UTC+7

## Goal

Design §2.7 / §6.5 / §6.7: write `<journey>.runbook.md` (literal curl per step, expected body and next callbacks)
and the report (`out/index.html`, `out/report.json`, `out/report.md`). Add the `report` and `all` commands;
`gen` writes `.sh` + `.runbook.md`.

## Steps

- [x] `src/generate/runbook.ts` (built in TS, no `runbook.md.eta`: the Markdown is mostly per-step code blocks): setup, inputs table, start call (with
      zero-page headers), one section per step with curl + JSON body (string inputs as `"<IN_X>"`, numbers and
      booleans as defaults, solver inputs as `"<computed: id>"`), variant sub-sections, optional/suspend/manual
      notes, "Expected next" (next step's types or `tokenId`)
- [x] `src/generate/report.ts`: summary row per journey (steps text, coverage, main note), `report.json`
      (per journey: steps, callbacks, coverage, notes, warnings, unreachable, unknown types, inputs, files),
      `report.md` (table + warnings), `index.html` via `src/templates/report.html.eta` (self-contained,
      light/dark, links to each journey's files)
- [x] CLI: `gen` also writes the runbook; `report` writes the three report files; `all` = gen + report;
      `--min-coverage <full|partial|manual>` makes `report`/`all` exit 2 when a journey is below (CI)
- [x] Tests: runbook snapshot (Login, DemoSignup), report JSON shape and table rows match design §6.7,
      HTML contains every journey and escapes names; CLI e2e (`all` into a temp dir)
- [x] Lint, typecheck, tests, build; update CLAUDE.md commands; commit

## Decisions

- Steps column: count of non-optional, non-suspend steps, plus `(+N optional)`; suspend/manual/OTP are
  explained by the note column instead of the count.
- HTML escaping done in the template helper (eta autoEscape stays off for `.sh`/`.md`).

## Results

- `all` on the sample: 13 journeys, 7 full, 5 partial, 1 manual; `--min-coverage partial` exits 2 (passwordless2).
- Report rows match design §6.7 (Login `1 (+1 optional)`, DemoSignup `6`, Agent `0` headers only, Registration
  `1` stops at Email Suspend, UpdatePassword/frAuth2 partial, passwordless2 manual).
- Runbook: one compact JSON line per callback, inputs table per step, variant sub-sections with solver labels,
  suspend steps/variants show the `suspendedId` resume curl.
- Extra: `src/generate/write.ts` (file writing outside the CLI); variant plain text now distinguishes random
  challenges from data-driven variants ("Depending on your account, ...").
- Tests: 72 passing (new `test/report.test.ts`: 14 incl. 5 snapshots).
- CLI e2e is covered through `writeJourneyFiles`/`writeReport` in a temp dir rather than spawning the built CLI.
